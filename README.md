# Contratiempo

RPG por turnos para un solo jugador en Fortnite, creado con UEFN y Verse. Un archipiélago amenazado por el Silencio y un combate en el que esquivar y bloquear al ritmo lo es todo.

- Diseño del juego: [docs/DISENO.md](docs/DISENO.md)
- Instrucciones para Claude Code: [CLAUDE.md](CLAUDE.md)
